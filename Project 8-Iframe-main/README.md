# Project – I-Frame Dashboard 🖥️

A simple **HTML and CSS project dashboard** that uses an **iframe** to display different projects within the same page.

## ✨ Features

- Sidebar navigation for multiple projects
- Displays projects inside an iframe
- Dark-themed modern interface
- Hover effects on navigation buttons
- Responsive full-page layout using Flexbox

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- Iframe
